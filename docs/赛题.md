
## 赛题简介

聚焦视觉语言模型（VLM）在边缘计算平台的高效部署。参赛者需基于通义千问Qwen3.5-2B模型，在阿里云PPU服务器上进行模型推理优化与部署实践，系统探索并提升模型在特定硬件上的性能。赛题鼓励从算法模型压缩到系统级算子融合、计算调度、内存管理、指令集优化等全栈技术方案的创新，旨在推动视觉语言模型在边缘计算场景的落地，培养具备软硬件协同优化能力的跨学科人才。

## 核心任务

**1**基于通义千问Qwen3.5-2B模型进行模型部署

**2**在阿里云PPU服务器上开展推理优化与部署实践

**3**探索算法模型压缩（量化、剪枝等）技术方案

**4**进行系统级优化：算子融合、计算调度、内存管理

**5**针对硬件特性进行指令集优化

**6**完成优化前后性能对比分析

## 作品要求

基线模型部署与性能测试报告

优化方案详细说明与源代码

部署前后性能对比分析文档

技术报告（含方法总结与实现细节）

## 评比规则

**模型推理精度**30%

优化后模型在测试集上的准确率保持程度

**推理延迟优化**30%

首Token延迟和端到端延迟的改善幅度

**吞吐量提升**20%

单位时间内处理请求数量的提升比例

**系统级优化**20%

算子融合、计算调度、内存管理等全栈优化深度

**评分公式：**总分 = 0.3 × 精度保持 + 0.3 × 延迟优化 + 0.2 × 吞吐量 + 0.2 × 系统级优化

## 详细评分标准

### 初赛评价指标

模型推理精度（Ability）

精度测试基于主办方提供的专用评估数据集进行，包含（图像，问题，参考答案）三元组。模型精度以匹配正确的样本数量占总样本数量的比例计算，即准确率。

Ratio_accuracy = 1 (当 P ≥ P_max)；Ratio_accuracy = (P - P_min) / (P_max - P_min) (当 P < P_max)

Time to First Token (TTFT) 提升率

衡量模型从接收完输入到产出第一个Token所需的平均时间。

TTFT提升率 = (T_ori - T_opt) / T_ori = 1 - T_opt / T_ori

吞吐量（Throughput）提升率

衡量模型单位时间内生成Token的平均速度（tokens/s）。测试在单样本输入且不启用批处理的场景下进行。

吞吐量提升率 = (T_opt - T_ori) / T_ori = T_opt / T_ori - 1

总分计算

总分 = 0.4 × (准确率 / 最高准确率) + 0.3 × (TTFT提升率 / 最高TTFT提升率) + 0.3 × (吞吐量提升率 / 最高吞吐量提升率)

初赛所有代码将采用赛事组提供的标准化硬件与软件环境进行统一复现与评测。
