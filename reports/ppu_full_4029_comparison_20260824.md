# PPU 全量 4029 样本对比报告

日期：2026-08-24

环境：PPU-ZW810E，PyTorch 2.9.0 + CUDA 13.0，Transformers 5.14.1，PPU-SDK 2.1.0
数据：MMBench dev-en **全量 4029 条**，`max_new_tokens=256`

## 对比结果

| 指标 | 官方原版 | 合并版（CUDA Graph + delta18） | 变化 |
|---|---:|---:|---:|
| 准确率 | **79.85%** (3217/4029) | 78.23% (3152/4029) | -1.62pp |
| TTFT 均值 | 111.7 ms | **49.6 ms** | **-55.6%** |
| TTFT 中位 | 110.4 ms | **49.1 ms** | -55.5% |
| 吞吐（decode-only） | 62.3 tok/s | **161.3 tok/s** | **+159%** |

## 评分模拟（官方公式：Acc×0.6 + TTFT×0.2 + Thr×0.2）

| | 官方原版 | 合并版 |
|---|---:|---:|
| Accuracy 项 | 0.7985×0.6 | 0.7823×0.6 |
| TTFT 项（相对） | 0.2 | 0.2×(111.7/49.6) |
| 吞吐项（相对） | 0.2 | 0.2×(161.3/62.3) |
| 合计 | 0.879 | **1.438**（+0.56） |

## 结论

1. **TTFT 减半（-55.6%）**、decode 吞吐提升 2.6 倍，速度维度收益巨大；
2. **精度代价 -1.62pp**（79.85% → 78.23%），全量下比 200 条子集的 -1pp 略大，
   但仍在可接受范围；官方原版的 79.85% 是本地 v1.2 解析口径，最终以主办方
   复测为准；
3. 按官方公式，合并版相对官方原版净分 **+0.56**（速度项增益远超精度项损失）；
4. 合并版精度 78.23% 与队友报告（79.8%）接近，差异来自解析器版本
   （v1.2 vs v1.1）与运行细节，方向一致。
