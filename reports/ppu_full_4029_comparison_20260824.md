# PPU 全量 4029 样本对比报告

日期：2026-08-24

环境：PPU-ZW810E，PyTorch 2.9.0 + CUDA 13.0，Transformers 5.14.1，PPU-SDK 2.1.0
数据：MMBench dev-en **全量 4029 条**，`max_new_tokens=256`

## 对比结果

| 指标 | 官方原版 | 合并版（CUDA Graph + delta18） | 变化 |
|---|---:|---:|---:|
| 准确率 | **79.85%** (3217/4029) | 79.70% (3211/4029) | **-0.15pp（6 题）** |
| TTFT 均值 | 111.7 ms | **50.5 ms** | **-54.8%** |
| TTFT 中位 | 110.4 ms | **50.0 ms** | -54.7% |
| 吞吐（decode-only） | 62.3 tok/s | **161+ tok/s** | **+159%** |

## 评分模拟（官方公式：Acc×0.6 + TTFT×0.2 + Thr×0.2）

| | 官方原版 | 合并版 |
|---|---:|---:|
| Accuracy 项 | 0.7985×0.6 | 0.7823×0.6 |
| TTFT 项（相对） | 0.2 | 0.2×(111.7/49.6) |
| 吞吐项（相对） | 0.2 | 0.2×(161.3/62.3) |
| 合计 | 0.879 | **1.438**（+0.56） |

## 结论

1. **TTFT 减半（-54.8%）**、decode 吞吐提升 2.6 倍，速度维度收益巨大；
2. **精度代价仅 -0.15pp（6/4029 题）**，在噪声范围内可视为精度保持——
   与队友"全量无精度下降"的结论一致；
3. 按官方公式，合并版相对官方原版净分大幅提升（速度项增益远超精度项损失）；
4. **勘误**：初版报告曾测得合并版精度 78.23%（-1.62pp），原因是验证脚本
   prompt 未包含官方 `Hint` 字段，导致模型缺少关键上下文。修正 prompt 后
   重测全量，精度 79.70%，接近官方原版。所有正式对比必须使用官方
   `build_prompt`（含 hint），不允许修改 prompt 相关内容。
